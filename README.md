# Grandpa's Games

A collection of small, gentle games made for the grandkids. Each game lives in
its own folder with its own README and run instructions.

| Game | Folder | What it is |
|---|---|---|
| Baker's Undersea Adventure | `bakers-undersea-adventure/` | A point-and-click adventure in the Freddi Fish tradition. Python / pygame-ce. |
| Peek-a-boo | `peek-a-boo/` | Coming soon. |

## Running a game

Each folder is self-contained. For example:

```bash
cd bakers-undersea-adventure
pip install -r requirements.txt
python main.py
```
