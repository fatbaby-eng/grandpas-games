# Music

Composed and rendered by `tools/compose_theme.py` (numpy only; ffmpeg for the
MP3/OGG encodes). The WAV masters are not committed because of their size; run
the script to regenerate them in a few seconds.

| File | What it is |
|---|---|
| `opening_theme_instrumental.*` | Full 78 s arrangement, music only |
| `opening_theme_with_narration.*` | Same, with the narrator over the opening and the music ducked underneath |
| `opening_narration_voice_only.*` | Voice stem alone, on the same timeline, for re-mixing over a different track |
| `underwater_loop.*` | 24 s seamless loop of the theme used in the game as the underwater music |

The arrangement: harp and a soft string pad open; the flute states the theme
twice (celesta answering the second time) over cello and a light shaker; a
string bridge with timpani; the full theme with flute and strings in thirds and
bells; a short outro to a held F major chord.

Timings and the narration text are in `NARRATION_SCRIPT.md`.
