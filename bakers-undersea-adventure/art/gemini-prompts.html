Baker's Undersea Adventure

Art prompts for Gemini

Every picture the game still needs, as a prompt you can paste straight into Gemini. Tick things off as you save them; the page remembers on this computer.

1. Attach the referenceEach card names an image to attach first. It keeps every result in the same painted style as Baker and the reef.
2. Paste the promptPress Copy, paste into Gemini with the image attached, generate. If the result has a shadow, text or a background, say “Again, on plain white with nothing else” and regenerate.
3. Save with the exact nameSave the result into the folder shown on the card with the file name shown. Spelling matters; the game finds files by name.
4. Rebuild and lookIn bakers-undersea-adventure run python tools/build_web.py, reload web/index.html. White backgrounds are removed automatically when I pull the files in; transparent PNGs are even better.
Rules the game depends on
  • Characters, items and props: one subject on plain white, facing right. The game flips them when they need to face left.
  • Talk frames: generate the idle picture first, then attach that result and use the talk prompt, so only the mouth changes.
  • Backgrounds: 16:9, no characters, bottom third open sand.
  • Done and optional cards are collapsed; use the filter to hide them.
